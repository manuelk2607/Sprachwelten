# Was soll das heißen?

Ein eigenständiges Sprachspiel: echte Redewendungen entdecken, Bedeutungen erfinden und mit Freunden bluffen.

Die öffentliche Sammlung und das Spiel können ohne Konto genutzt werden. Eigene Redewendungen und Erklärungen erfordern eine Anmeldung per E-Mail und Passwort.

Das Datenmodell bereitet Dialektbeiträge und Alltagssituationen vor.

Die erste spielbare Version wird in diesem Repository aufgebaut.
